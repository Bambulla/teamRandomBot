# ра [бот] аем

VK Teams-бот для московских коллег Рокета по механике random coffee: раз в неделю бот случайно формирует пары для 30-минутного общения, чтобы команды были в контексте того, что происходит у соседей.

## Идея

Какой хороший день, чтобы узнать про наш проактивчик.

Бот помогает неформально синхронизировать разные команды внутри Рокета. Участники, которые попались друг другу, списываются в личке, находят общий свободный слот на 30 минут и встречаются: можно рассказать, что нового в отделе или продукте, поштормить над задачей на свежую голову или просто поболтать.

## Сообщения и команды

- `/start` или `/help` — первое сообщение с описанием бота.
- `/poll` — сообщение-опрос «хочешь ли ты участвовать?».
- `/join должность, отдел` или `+` — включиться в еженедельные пары; должность и отдел сохраняются, чтобы участникам было проще представиться.
- `/leave` или `-` — временно не участвовать в ближайших парах.
- `/participants` — показать активных участников.
- `/pairs` — составить пары на текущую неделю и сохранить результат.
- `/week` — показать уже составленные пары текущей недели.
- `/react @user текст` — сохранить реакцию после встречи.
- `/reactions` — показать реакции за сегодня.
- `/ping` — проверить, что бот жив.

Пример сообщения в общий чат после `/pairs`:

```text
Пары для чата составлены!
Смотри, с кем встречаешься на этой неделе:

Напишите друг другу в личку, чтобы договориться на свободный слот на 30 минут, чтобы почирикать о рабочем и всяком.
```

## Подготовка бота в VK Teams

Проект использует официальный Python SDK `mailru-im-bot`.

1. Создайте бота через `@Metabot` в VK Teams и получите токен.
2. Узнайте URL Bot API вашего контура. По умолчанию SDK использует `https://api.icq.net/bot/v1`; для VK Teams/Myteam-контура укажите адрес вашей инсталляции, например `https://myteam.mail.ru/bot/v1`.
3. Скопируйте `.env.example` в `.env` или экспортируйте переменные окружения вручную.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
export BOT_TOKEN="ваш_токен"
export BOT_API_URL="https://myteam.mail.ru/bot/v1"
export DATABASE_PATH="data/team_random_bot.sqlite3"
team-random-bot
```

Также можно запускать модуль напрямую:

```bash
python -m team_random_bot.bot_app
```

## Хранение данных

Бот хранит участников random coffee, пары текущих недель и реакции в локальной SQLite-БД. Путь задаётся переменной `DATABASE_PATH`; по умолчанию используется `data/team_random_bot.sqlite3`. Таблицы создаются автоматически при старте.
